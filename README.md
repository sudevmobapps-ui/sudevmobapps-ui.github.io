# sudevmobapps-ui.github.io

SuDev's public site: `app-ads.txt` at the root, and the pages the app stores ask for - an about
page, a privacy policy, terms and account deletion, each in English and Turkish.

- `/app-ads.txt` - the AdMob publisher id, which has to sit at a domain root. A user site serves
  it there; a project site would bury it one folder down, where the crawler does not look.
- `/puzzclash/` - PuzzClash
